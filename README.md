# Computer Science B

Coursework repository for **COCS-221: Computer Science B** at AUPP.

## About

This repo tracks my labs, weekly exercises, and course materials as the semester progresses. It's organized into two parallel tracks:

- **`Lab/`** — Formal lab assignments (handed out as PDFs, completed as Jupyter notebooks)
- **`Week/`** — Weekly in-class exercises and topic-based practice

> **Note:** The contents of `Lab/` and `Week/` are updated continuously as the course advances. New `LabN/` and `WeekN/` folders are added each time a new lab or weekly topic is introduced — this structure is a living snapshot, not a fixed layout.

## Conventions

- Each `LabN/` folder contains the assignment sheet (`LabN.pdf`) alongside the completed notebook (`labN.ipynb`) and any supporting/output files it generates.
- Each `WeekN/` folder holds materials and practice notebooks tied to that week's topic (e.g., Week 3 = Dictionaries).
- `.pkl` and `.txt` files inside lab folders are typically data generated or consumed by that lab's notebook — not meant to be edited by hand.
